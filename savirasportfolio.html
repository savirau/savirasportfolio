Projects and Research

Implementation Of EfficientNetV2-S-Based Ensemble Learning with Explainable AI Integration for the Prediction of Pulmonary Tuberculosis Using Chest Images

Thesis Research Project
  • Project Overview:
    • An AI-powered diagnostic system implementing an Ensemble Learning approach with an EfficientNetV2-S backbone and Explainable AI (XAI) integration to classify Pulmonary Tuberculosis from thoracic Chest X-Ray (CXR) images.
  • Key Performance Metrics:
    • Validation Accuracy: 98.675% (±0.517%) evaluated via 10-Fold Cross-Validation across 10,903 images.
    • Inference Speed: 31.67 ms/image, enabling rapid screening capabilities.
  • Technical Highlights & XAI Analysis:
    • Architecture: Leveraged an ensemble strategy built on EfficientNetV2-S (Fused-MBConv & MBConv layers) with targeted fine-tuning for robust feature extraction.
    • Model Transparency (Grad-CAM): Applied XAI to visually audit model decisions, exposing shortcut learning (distractions from "R" markers and non-medical artifacts) and domain shift issues when tested on primary hospital data.
    • Translational Value: Emphasizes the need for standardized image acquisition and local annotated datasets for safe real-world clinical deployment.

Hydrolink: Smart Hydration Monitor Based on GSR & ESP32

IoT & Biomedical Hardware
  • Project Overview:
    • An IoT-based smart bottle designed for non-invasive, real-time body hydration monitoring.
  • System Operations:
    • GSR (Galvanic Skin Response) Sensor: Measures skin conductivity to detect hydration levels (high conductivity = well-hydrated; low = dehydrated).
    • Dual ESP32 Microcontrollers: The master ESP32 processes sensor data using one core, while its second core handles Wi-Fi connectivity and Telegram alerts. If dehydration is detected, it wirelessly signals the slave ESP32 to activate a piezoelectric buzzer.
    • Telegram Notifications: Sends real-time updates containing the detection timestamp, hydration status, and recommended actions.

Nemo: Anemia Detector

Prototype Based on IoT & Deep Learning
  • Project Overview:
    • An end-to-end health monitoring system driven by IoT and deep learning, designed to estimate hemoglobin (Hb) concentration and predict anemia risks in real time without needle-based blood extraction. The project seamlessly integrates custom medical acquisition hardware with an Android mobile application to provide a comfortable, rapid, and infection-free screening alternative for point-of-care diagnostics.
  • System Operations:
    • On the hardware end, the system utilizes a MAX30102 pulse oximetry sensor interfaced with a microcontroller to extract raw Photoplethysmography (PPG) signals across the Red and Infrared light spectrums. These optical signals are wirelessly streamed via Bluetooth to the smartphone client. For signal interpretation, a Long Short-Term Memory (LSTM) neural network architecture was engineered in TensorFlow/Keras to capture time-series sequential patterns from the PPG waveform, integrating demographic variables including user age and biological sex as contextual parameters.
  • Performance & Features:
    • The Android application delivers a user-centric experience, offering real-time Hb and SpO2 tracking, interactive historical trend visualization, instant diagnostic indicators (Normal vs. Anemic), and direct access to health consultations. During quantitative performance benchmarks, the model demonstrated strong predictive capability, achieving a Mean Absolute Percentage Error (MAPE) of 14.45% and an R2 coefficient of 0.7729 (explaining 77.29% of variance in hemoglobin levels), alongside validation metrics of MAE: 0.5361, RMSE: 0.8356, and MSE: 0.6983.
